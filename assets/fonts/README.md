# Fonts

`ArchivoDitch-*.ttf` are static instances of the Archivo variable font (Google Fonts, latin subset, SIL Open Font License 1.1, see `OFL-Archivo.txt`). Made with fonttools `varLib.instancer`, renamed so iOS sees five separate fonts:

| File | Width | Weight | Used for |
|---|---|---|---|
| ArchivoDitch-Wordmark | 125 | 900 | "ditch" wordmark, Pro lockup |
| ArchivoDitch-Display | 118 | 900 | Big headlines, the yearly total |
| ArchivoDitch-Title | 115 | 900 | Screen titles |
| ArchivoDitch-WideHeavy | 110 | 800 | Money, month names, the lock-screen clock |
| ArchivoDitch-WideBold | 110 | 700 | Smaller money in lists |
