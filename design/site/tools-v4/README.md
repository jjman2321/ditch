# Site UI v4 mockups (Nov 13, 2026)

Owner feedback: "our ui rn is ass". Mobbin research, screen by screen, then one mockup per page type.
Open the .html files in a browser, or see the -desktop.png / -phone.png renders.

| Page | What's wrong now | Inspo (Mobbin) | Change |
|---|---|---|---|
| Tools hub | Long grey text list, tiny arrows, no logos. Looks like a sitemap. | Upwork tools hub, Intercom / Vercel / Homerun integration grids, Customer.io search | Search box, 3 big "most used" cards (ink + sunflower), groups as H2 left + 2-col cards with real service logos (pairs for vs) |
| Tool page | Small form, answer is plain text in the same box, narrow column wastes desktop | Upwork Marketing Budget calc, incident.io cost calc, Kit, Hers, ClickUp | Inputs left, dark result panel right with a huge sunflower number + bar "alone vs shared". Segmented control and +/- stepper instead of dropdowns. Service logo in hero. Steps as 3 cards, FAQ in 2 columns |
| vs page | Two stacked plan lists, no clear winner | Craft "Free vs Plus" table, Sketch compare, Hims compare | One table: logos head the columns, rows by plan type, the cheaper price gets a sunflower pill, one-line answer under it |
| Cancel guide | Narrow single column, empty sides on desktop | Miro help center (article + "On this page"), OpenTable help | Sticky right rail: sunflower "Quick answer" card with the cancel button + On this page. "Pick how you pay" as 3 cards |

Phone: everything stacks to one column, chips scroll sideways, result panel sits right under the inputs.
